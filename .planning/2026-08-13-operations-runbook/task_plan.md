# 项目操作手册沉淀计划

## 目标

形成可迁移到 Codex CLI、桌面客户端或新会话的单一权威操作手册，准确说明从新闻发现、Markdown 报告生成到 HTML 构建、验证和可选发布的完整流程。

## 阶段

- [x] 用户确认手册结构与不改变生产行为的边界
- [x] 盘点当前代码、脚本、文档、测试和发布入口
- [x] 建立文档契约测试并观察预期失败
- [x] 编写 `docs/OPERATIONS_RUNBOOK.md`
- [x] 在 `HANDOFF.md` 增加权威入口与新会话读取顺序
- [x] 运行命令、链接、文档契约和完整回归验证
- [x] 记录最终状态、未执行操作和迁移边界

## 约束

- 不修改新闻算法、HTML 模板、现有报告、自动任务或发布状态。
- 不读取或记录密码、Cookie、Local Storage、浏览器历史或运行时令牌。
- 保留主工作区现有未提交修改，不纳入本轮变更。
- 本轮不提交、不推送、不发布，除非用户另行授权。
