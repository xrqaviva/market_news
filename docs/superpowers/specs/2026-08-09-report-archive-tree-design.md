# 报告归档窄侧栏与日期树设计

## 背景与目标

当前桌面端报告归档将每份报告按“日期 + 时段”平铺，并占用220px固定宽度。目标是在不改变新闻内容和报告切换能力的前提下，提高正文屏幕利用率，并把归档改成清晰的“日期 → 时段”两级树。

## 已确认设计

- 采用日期手风琴树；初始进入站点时所有日期节点收起。
- 日期为一级节点，按最新日期在上排列。
- 时段为二级链接，同一天固定按盘前、盘中、盘后排列。
- 历史元数据“收盘”只在导航展示层规范为“盘后”；报告正文和原始Markdown不改动。
- 点击日期同时打开该日期节点并切换到该日时间最晚的一份本地报告；其他日期保持收起。
- 展开后只显示该日期在本地实际存在的报告，不补造缺失的盘前、盘中或盘后。
- 日期下默认高亮刚打开的当日最新报告；用户随后可点击同日其他现有时段。
- 进入站点默认展示最新日期的最新一份报告，但侧栏日期仍保持全部收起，直到用户点击日期。
- 删除侧栏中的“报告归档”标题。
- 桌面端侧栏和顶部品牌列由220px缩至约120px；日期、箭头和树线之外的横向总留白约30px，目标是刚好完整显示内容。
- 移动端仍隐藏侧栏并使用现有报告下拉框；选项保持“日期 · 时段”语义。

## HTML结构与数据流

`web/build.py`继续以完整报告索引作为唯一输入。归档渲染器先按日期分组，再按日期降序、时段优先级排序，输出语义化列表：归档根列表包含日期组，每个日期组包含日期入口和隐藏的时段链接列表。日期入口的目标是该组中时间最晚的真实报告。

日期入口使用URL片段标记需要展开的日期。首次从站点首页进入最新报告时没有片段，所以全部日期收起；点击日期后导航到“当日最新报告 + 日期片段”，页面加载时只展开对应日期。点击二级时段时保留同一日期片段，使报告切换后该组继续展开。整个过程不使用Cookie、Local Storage或Session Storage。

每个二级链接继续保留原有相对HTML地址与当前页的`aria-current="page"`。JavaScript仍通过归档区域中的二级报告链接生成移动端下拉选项，因此不新增第二份导航数据。

## 视觉规则

- 约120px侧栏以正文屏效优先，完整容纳日期、展开箭头、树线和四字以内时段；横向总留白约30px。
- 日期使用较弱颜色、小字号、等宽数字和展开箭头，既承担分组标题也是当日最新报告入口。
- 二级链接缩进，并使用左侧树枝线或等价的细线连接；当前项使用现有蓝色强调和深色背景。
- 收起时只显示日期行；展开时组内距小于组间距，形成清楚层次；不使用大面积卡片。
- 820px及以下的现有移动端断点和正文布局保持不变。

## 兼容性与异常边界

- 时段排序优先使用报告`slot`：早间为盘前、日间为盘中、下午及收盘为盘后；未知时段排在已知时段之后，并保留原标签，避免丢失报告。
- 同一日期、同一时段若未来出现多份报告，全部保留，并以时间字段和稳定输入顺序确定顺序，不覆盖链接。
- URL片段不存在或不匹配任何本地日期时，全部日期保持收起；页面报告内容仍正常显示。
- 日期入口的最新报告从该日期真实报告集合计算，不依赖固定存在盘后报告。
- 报告索引为空的构建错误仍由现有构建验证处理，本次不新增空状态页面。
- 新闻筛选、详情展开、来源链接、热点权重、首页重定向和公开安全规则均不在本次改动范围。

## 测试与验收

1. 单元/渲染契约：构造跨日期和同日多时段索引，断言日期只出现一次、日期降序、同日盘前在盘后之前、“收盘”导航显示为“盘后”、日期入口指向当日真实最新报告，且只渲染真实存在的时段。
2. 集成构建：重建全部历史HTML，断言每份报告均有两级树且所有归档链接仍能解析。
3. 交互契约：无URL片段时全部日期收起；点击2026-07-30后打开当天盘后并只展开该日，盘后高亮；同组二级链接切换后该日保持展开；错误片段安全降级为全部收起。
4. 移动端兼容：下拉选项数量与报告数一致，选项包含日期和规范化时段，当前报告正确选中。
5. 桌面浏览器UAT：确认侧栏约120px、没有“报告归档”标题、日期完整无截断、正文宽度增加、初始日期全部收起；点击2026-07-30后只显示本地已有的盘前和盘后并默认选择盘后；报告切换正常。
6. 回归：新闻筛选、Top 10详情展开、后续条目直接来源、无横向滚动和控制台零错误。
7. 安全与发布：公开树安全扫描、JavaScript语法、生成资产一致性、`git diff --check`和完整测试套件通过后，才同步公开站点。

## 权限与发布边界

源码、测试、生成HTML和UAT记录在隔离分支内修改。公开仓库同步、提交和推送沿用用户已授权的站点发布流程；不修改定时任务、新闻Markdown或主工作区其他未提交内容。

## 非目标

- 不增加月份第三级、搜索或分页。
- 不记忆上次展开日期；每次无日期片段进入时均全部收起。
- 不重新设计移动端导航。
- 不改变任何新闻排序、评分或内容字段。
