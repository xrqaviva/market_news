# A股短线新闻雷达：交易日窗口、跨时区与紧凑版式设计

## 目标

新闻雷达默认覆盖前一交易日当天至当前交易日报告截点的全部相关新闻，休市日不形成采集断层。窗口之外的旧新闻若在本窗口内热度显著提升，仍进入统一主榜。报告采用紧凑版式：每条先展示标题和核心信息，再按传播渠道与北京时间展示传播链；核验链接直接嵌入表格详情文字，不另设核验路径行。

## 统一时间基准

- 候选纳入、传播链排序、监控快照比较和报告展示统一采用 `Asia/Shanghai`。
- 海外来源先根据页面明确给出的当地时间和时区换算为北京时间，再判断是否落入新闻窗口。
- 夏令时按事件发生当日对应地区的有效规则换算，不使用当前日期的时差反推历史时间。
- 原始当地时间、原始时区标识及换算结果保存在证据表；主报告默认只展示北京时间。
- 来源未给出明确时区时，不擅自换算；标记“来源时区未确认”，同时保留页面原始时间文本。
- 只有日期、没有分钟时，保留北京时间日期并标注“精确分钟未取得”，不虚构 `00:00`。

## 新闻窗口

令 `T` 为当前A股交易日，`P` 为中国内地证券交易所交易日历中的前一交易日，`C` 为本次报告截点：

`主新闻窗口 = [P 00:00:00, C]`，时区统一为 `Asia/Shanghai`。

具体规则：

- 普通交易日：从前一交易日00:00开始，覆盖前一交易日盘前、盘中、盘后以及当前交易日截至报告截点的全部新闻。
- 周一：从上周最后一个交易日00:00开始，连续覆盖周五、周末和周一截至报告截点的全部新闻。
- 节假日后首个交易日：从节前最后一个交易日00:00开始，连续覆盖节前交易日、全部休市日期和节后首个交易日截至报告截点的全部新闻。
- 临时休市或特殊交易安排以交易所交易日历为准，不以自然日、工作日或简单“减一天”推算。
- 休市期间持续采集并保存快照；下一交易日报告统一归并，不能只抓复市当天。
- 若在非交易日生成临时观察版，沿用最近一个交易日00:00作为起点，并明确标注“休市观察版”；正式主榜在下一交易日重新归并。

## 窗口外旧闻重新升温

旧新闻的原始发布时间可以早于主新闻窗口。只要其在本窗口内出现可核验的显著热度变化，仍进入统一主榜并参与热点权重排序，不另建不参与排序的附属榜。

旧闻异动至少满足下列一项：

- 同平台同字段互动或搜索结果量达到既有“明显升温”或“激增”门槛。
- 热榜上升至少10位，或由未上榜进入前20。
- 两个及以上独立平台在本窗口内同步明显升温。
- 旧帖或旧报道在本窗口内被权威媒体、官方渠道或高热社区重新传播，并取得可核验的新榜位或互动增量。

每条旧闻异动必须同时展示：

- 原始事件、原帖或报道的最早可核时间。
- 本窗口重新升温的首个可核时间。
- 热度变化的起点、终点、绝对增量及适用时的相对增幅。
- “旧闻异动”状态标签。

不得把本轮重新发现时间写成原始发布时间，也不得仅凭主观印象把旧闻标记为升温。

## 主榜纳入与排序

- 窗口内新消息和窗口外旧闻异动进入同一候选池。
- 热点权重继续使用：覆盖25 + 变化30 + 绝对热度20 + 新鲜度15 + 频次10。
- 热度变化继续参与主榜排序，且为权重最高的单项。
- 旧闻的新鲜度按原始发布时间计，不因重新升温而伪装成新消息；其本轮异动由变化分和频次分体现。
- 可靠性、资金验证、个股映射和公告确认不参与排序，缺失不影响消息入榜。
- 同一事件跨平台合并；不同事实触发点不因属于同一题材而强行合并。

## 每条新闻的紧凑版式

每条新闻按以下顺序展示。

### 1. 标题行

同一行展示：

- 排名与标题。
- 热点权重。
- 状态标签，如“新出现”“明显升温”“激增”“旧闻异动”“趋势未知”。

### 2. 核心信息

用一至两句说明：

- 发生了什么。
- 本轮为何值得关注。
- 当前最关键的传播或热度结果。

事实和社区推演必须分开；不提供“一眼结论”和操作建议。

### 3. 传播渠道与北京时间表

紧接核心信息展示紧凑表格：

| 传播渠道 | 北京时间 | 消息或热度 |
|---|---|---|
| 首发、官方或公司源 | 最早可核时间 | 可点击的核心事实描述 |
| 财经媒体 | 报道时间 | 可点击的报道进展 |
| 微博、雪球、X、韭研、淘股吧等 | 帖子或采集时间 | 可点击的具体帖子及原始互动 |
| 榜单或监控快照 | 快照时间 | 榜位或同字段起点→终点 |

表格要求：

- 所有时间按北京时间从早到晚排列。
- “消息或热度”中的具体事实、报道标题、帖子描述或榜单名称直接设置为对应永久链接。
- 不另设“核验路径”一行或链接堆叠段落。
- 同一渠道存在多个重要节点时可以多行展示，不能为了压缩而漏掉时间或热度变化。
- 首页和搜索页不能替代具体帖子或文章；动态榜单没有历史快照证据时，不声称其历史榜位可以永久复现。
- 海外来源的原始当地时间只在时区容易混淆或换算存在特殊情况时，以短注形式补充。

### 4. 紧凑尾注

表格下使用最多三行紧凑展示：

- `热度`：监控区间、各平台变化及变化判定。
- `传播`：首发 → 媒体 → 社交平台 → 社区映射。
- `边界`：可靠性、尚未确认内容和可选A股附注。

热点权重五项分值可放在标题行后的短注或折叠式括号中，不占用独立段落。

## 数据和证据要求

每个传播节点保存：

- 事件ID和渠道名。
- 页面标题、永久链接及来源类型。
- 页面原始时间文本、原始时区、换算后的北京时间。
- 首次发现时间和最近复核时间。
- 可见的原始互动字段或榜位。
- 快照口径、采集成功或失败状态。

时间窗口纳入判断只能使用换算后的北京时间。报告表格与证据表中的北京时间必须逐条一致。

## 异常处理

- 页面只有相对时间时，若能以带时区的采集时间可靠换算则记录换算过程；否则写“精确时间未取得”。
- 来源时区、夏令时或发布日期存在歧义时，保留原始文本并披露歧义，不以不确定时间决定首发顺序。
- 渠道抓取失败写“未取得”，不等同于没有相关消息。
- 上一快照没有成功覆盖相同来源和关键词时，不把当前首次发现伪装成“未发现→当前值”。
- 旧闻只有单次当前快照时可进入候选，但状态写“重新出现、趋势数据不足”，不标记激增。

## 验收标准

- 报告顶部明确列出前一交易日、当前交易日、新闻窗口起点、报告截点和统一时区。
- 周一和节假日后的测试样例能够覆盖两个交易日之间的全部自然日。
- 海外样例同时保存原始时区信息和北京时间，主榜按北京时间正确排序。
- 每条窗口内新闻均能说明其最早可核时间；不能取得时明确标注，并列出全部已取得节点。
- 每条旧闻异动均展示原始时间、本轮升温时间和同口径热度证据。
- 标题和核心信息位于条目最前；传播渠道与北京时间表紧随其后。
- 表格详情文字可直接点击进入具体文章、帖子、公告或榜单详情，不另设核验路径行。
- 不为压缩版式删除渠道、时间、互动字段、监控端点、可靠性边界或尚未确认内容。
- 总分等于五项分值之和，统一主榜按总分降序；同分按变化分和最近更新时间排序。
- 不出现把海外当地日期直接当北京时间、把发现时间冒充发布时间、把旧闻冒充新消息、首页替代具体帖子或操作建议。

## 本轮实施范围

下一步先将现有V4报告和证据表改造成上述窗口口径与方案A版式，并建立相应的结构和语义验收。自动调度、长期数据库和推送继续作为后续阶段，不在本轮扩展。
