# 新闻雷达高保真报告外壳设计

状态：用户于 2026-08-12 选择方案 2，确认按视觉设计页逐组件重建固定 HTML 模板和 CSS。

## 1. 目标与基准

生产报告必须高保真复刻已确认视觉用例 `layout-final-v3.html` 的页面容器、栅格、字体、间距、边框、圆角、阴影和对齐规则。视觉用例中的顶部“最终结构”说明和底部图例属于设计标注，不进入生产报告。

Markdown 仍是报告内容的唯一事实来源。核心方向、完整新闻、未归类的重要新闻、判断边界、市场反馈、来源、待核验线索及其他说明性内容不得因视觉改造缺失、截断或改变顺序。

## 2. 实现路径

采用逐组件重建方案：调整 `web/templates/report.html` 的固定外壳，使报告标题、侧栏和正文进入同一个报告卡片；重写对应的 `web/assets/app.css` 布局令牌和组件规则；保留现有渲染器数据接口和 JavaScript 交互契约。

不直接复制设计页的静态示例内容，不手工编辑生成结果 HTML，不修改新闻采集、解析、聚合、评分和排序逻辑。

## 3. 桌面几何规格

- 页面背景：`#edf1f6`。
- 页面容器：最大宽度 `980px`，水平居中，四周内边距 `27px`。
- 报告卡片：浅色背景，`2px solid #cad3e1`，`16px` 圆角，隐藏溢出，阴影 `0 16px 40px rgba(30,40,60,.10)`。
- 左侧归档：固定宽度 `76px`，深蓝背景 `#1c2940`，水平内边距 `9px`、顶部内边距 `17px`。
- 正文：`min-width: 0`，顶部/左右内边距分别为 `23px / 28px`。
- 正文与左栏自报告卡片顶部开始，贯穿完整报告高度；不得恢复独立的全宽顶部栏或 `120px` 左栏。
- 报告标题区底部为 `1px solid #dce2ea`；标题块和截止时间按底边对齐。
- 核心方向导航保持单行、水平滚动、间距 `16px`，上下内边距 `12px`。

## 4. 字体与层级

统一字体栈：`-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", sans-serif`。

- 报告眉题：`9px`，字距 `.12em`，颜色 `#7f8999`。
- 报告标题：`21px`、`800`。
- 截止时间：`9px`、`#8d96a5`。
- 导航：`10px`；当前方向使用品牌蓝并加粗。
- 核心方向眉题：`9px`、品牌蓝、`800`。
- 核心方向标题：`25px/1.15`，字距 `-.02em`。
- 条数和聚合分数：`8px`、浅灰、常规字重，只作为辅助信息。
- 催化说明：`10px`、`#5e697b`。
- 新闻排名：固定 `30px` 列，`12px Georgia, serif`，颜色 `#929cab`。
- 新闻标题：`12px`；新闻摘要和辅助信息：`9px`。

中文环境必须优先使用系统中文字体，不以 Inter 或等宽字体替代正文。

## 5. 对齐与区块节奏

- 核心方向区块内边距为 `23px 0 15px`。
- 相邻方向之间使用 `6px solid #edf0f4` 分隔带。
- 方向标题、聚合元数据采用基线对齐，间距 `7px`。
- 新闻列表距催化说明 `14px`，顶部使用 `2px solid #253047`。
- 新闻条目使用两列栅格：`30px minmax(0,1fr)`，列间距 `9px`，上下内边距 `12px`。
- 所有新闻标题、摘要、详情和来源共用同一内容左边线。
- 新闻条目之间使用 `1px solid #dfe4eb`。
- 详情、来源、关联标签和市场反馈均嵌入新闻内容列，不得形成额外的第三列或破坏标题基线。
- 未归类的重要新闻在全部核心方向之后使用同一新闻栅格，不得遗漏或被压缩为索引。
- 报告级方法、时间、风险、渠道状态、完整性和来源覆盖说明统一进入低视觉权重的“报告说明”区，保持 Markdown 顺序，位于新闻（含未归类的重要新闻）之后、待核验线索之前；基础文本、列表和 HTTP(S) 链接必须安全转义并保留。
- 待核验线索位于报告末尾，默认收起，视觉权重低于新闻正文。

## 6. 内容与交互契约

- 每个主题和每条新闻保持当前稳定 ID、来源链接、安全过滤和展开状态隔离。
- 只有来源而无额外详情的新闻直接显示来源，不出现空按钮。
- 存在详情的新闻保留展开/收起控件及键盘语义。
- 左侧归档继续按日期 → 盘前/盘中/盘后树状展示，默认选择最新日最新报告。
- 打印时完整展示新闻详情和待核验线索。
- “报告说明”在屏幕和打印中均保持可见，标题和正文使用紧凑字号；小字号颜色允许比视觉参考更深，以满足 `4.5:1` 动态对比度门禁，此为有意的可访问性偏差。
- 旧版非主题化报告继续兼容，不改变其数据内容。

## 7. 响应式规格

在 `700px` 及以下：

- 页面容器内边距改为 `12px`。
- 隐藏桌面左栏，保留移动报告选择控件。
- 报告正文内边距改为 `18px`。
- 核心方向标题改为 `21px`。
- 卡片的灰底、圆角、边框和整体层级继续保留。
- 核心方向导航水平滚动；不得产生页面级横向溢出。
- Markdown 内容保持完整，不以移动适配为理由删除字段。
