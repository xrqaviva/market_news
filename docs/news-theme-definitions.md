# 新闻题材分类定义（News Theme Definitions）

> 用途：为每条新闻分配「关联题材」的唯一依据。生成报告前先读本文件，按定义归类；
> 不同题材不得聚合到一个标签下，同题材内部也要区分概念层级（见各题材「不属于」）。

## 题材清单

### theme-ai-compute「AI算力 / 算力租赁 / 算力基建」

- **定义：** AI 算力的**需求、供给与基建**三件事：
  - 需求/资本开支：云厂商资本开支、美股算力租赁商业绩与订单（腾讯 Q2 capex、CoreWeave、Nebius、马斯克算力扩产、芝商所算力期货）
  - 供给/采购：算力采购、算力租赁、云算力实例（亿田服务器采购、阿里云超节点实例、腾讯云定价）
  - 基建：数据中心/IDC 投资、算力网政策、智算集群规划（龙旗收购安瑞可、四川算力网政策、福建一体化算力网）
  - 服务器整机与订单（联想 ISG 订单）也属此题材。
- **不属于（易混项，各归其位）：**
  - 光模块、光通信、CPO → `theme-cpo`
  - PCB、覆铜板、铜箔、电子材料 → `theme-pcb-materials`
  - 芯片设计/制造/存储 → `theme-semi-foundry`
  - 算力电力配套（算电协同）→ `theme-power`
  - 大模型、AI 应用 → `theme-ai-apps`
- **区分原则：** 光模块是算力网络的**传输层**，PCB/铜箔是**硬件材料层**，二者服务于算力但不属于算力需求/供给/基建本身；只有直接构成算力（服务器、集群、算力网、数据中心、资本开支、租赁采购）才算本题材。

### theme-cpo「光模块 / CPO / 光通信」（新增，自 theme-ai-compute 拆出）

- **定义：** 光模块、光通信设备、CPO（共封装光学）产业链。
- **典型成员：** 光模块厂商动态与投资（中际旭创、新易盛、天孚通信等）、海外光通信业绩（Lumentum、Coherent）、光模块散热等上游配套投资、光通信板块行情。
- **不属于：** 算力租赁/算力采购（→ `theme-ai-compute`）；光模块用 PCB（→ `theme-pcb-materials`）。
- **区分原则：** 新闻主体是「光模块/光通信公司或其产品」即归本题材，即使其业务服务于 AI 算力。

### theme-pcb-materials「PCB / 铜箔 / 电子材料」（新增，自 theme-ai-compute 拆出）

- **定义：** 印制电路板（PCB）、覆铜板、铜箔及电子材料产业链的产能、订单、业绩与投资。
- **典型成员：** PCB 厂商 AI 服务器/光模块 PCB 营收（鹏鼎控股）、铜箔扩产定增（亨通股份）、覆铜板/电子材料动态。
- **不属于：** 光模块本体（→ `theme-cpo`）；算力租赁/算力基建（→ `theme-ai-compute`）。
- **区分原则：** 新闻主体是「PCB/铜箔/材料厂商或其产品」即归本题材；标题出现"光模块 PCB"时看主体——是 PCB 营收/产能则归本题材，是光模块产品则归 CPO。

### theme-macro「宏观 / 货币政策 / 利率 / 贸易政策」（由 theme-overseas-macro 拆分重组）

- **定义：** 宏观政策与海外资产定价：
  - 货币政策：央行公开市场操作（逆回购/买断式逆回购）、降准降息、货政报告（央行逆回购 10000 亿、LPR）
  - 利率/美债：美债收益率、加息/降息押注（30 年期国债中标收益率、9 月加息押注）
  - 通胀数据：CPI/PPI
  - 美股行情与机构观点：指数涨跌、盈利预期（标普创新高、花旗/美银观点）
  - 贸易政策：关税、反倾销、出口管制（无人机关税、单模光纤反倾销）
- **不属于（易混项，各归其位）：**
  - 原油/天然气/黄金等大宗商品价格 → `theme-commodity`
  - 地缘事件（是否归本题材看是否直接定价于商品，见下）
- **区分原则：** 政策动作（央行/美联储操作、关税、反倾销）与资产定价（利率、指数、盈利预期）归本题材；商品价格本身的变动归 `theme-commodity`。

### theme-commodity「能源 / 商品」（由 theme-overseas-macro 拆分）

- **定义：** 大宗商品价格与供需：
  - 能源：原油、天然气（布伦特跌破 86、欧洲天然气期货下跌）
  - 贵金属：黄金/白银（金价反弹）
  - 工业金属/小金属等商品价格
- **地缘边界：** 直接影响商品价格的局势（霍尔木兹 → 油价）归本题材；纯宏观地缘（选举、政策）归 `theme-macro`。

### theme-semi-foundry「半导体 / 晶圆代工 / 存储芯片」

- **定义：** 晶圆代工、存储芯片、国产芯片设计/制造的业绩、产能、市值事件（中芯国际、华虹、海光信息、长鑫科技）。
- **不属于：** 光模块（→ `theme-cpo`）、PCB/材料（→ `theme-pcb-materials`）、AI 算力租赁/基建（→ `theme-ai-compute`）。

### theme-humanoid-robot「人形机器人 / 具身智能」

- **定义：** 人形机器人出货/产量统计、公司业务动态与澄清、行业大会/运动会（宇树、秦安股份、福赛科技、世界机器人大会等）。

### theme-ai-apps「AI应用 / 大模型」

- **定义：** 大模型发布与定价、AI 应用落地（OpenAI、DeepSeek、Grok、混元、微信小微、企业引入 Claude 等）。
- **区分原则：** 模型/应用层归本题材；模型背后的算力采购/资本开支归 `theme-ai-compute`。

### theme-a-share-buyback-capital「A股资本运作 / 回购 / 分红」

- **定义：** 回购提议、战略投资引入、高分红、定增获批等资本运作事件（颀中科技、均胜电子、吉比特、望变电气）。

### theme-consumer「消费 / 影视 / 乳业」

- **定义：** 影视票房、消费场景联动、乳业等消费板块行情与异动（《欢迎来龙餐馆》、一鸣食品、皇氏集团、北京文化）。

### theme-pharma「医药 / 创新药」

- **定义：** 创新药业绩指引、板块行情、药品注册、行业诉讼（百济神州、华润双鹤、礼来、国产胰岛素出海）。

### theme-power「电力 / 算电协同」

- **定义：** 用电负荷、电力板块行情、算电协同概念股异动（同力天启、广西/广东负荷创新高）。

## 分类操作规则

1. **先读定义再归类**：每条新闻先判断主体（公司业务/产品/事件类型），再查上表，禁止凭标题关键词（"AI""算力"）直接归类。
2. **按主体归类，不按受益链条**：某事件"利好算力"不等于属于算力题材；看新闻主体本身是什么（光模块公司 → CPO；PCB 厂商 → PCB）。
3. **不跨题材聚合**：一个题材章节只收同一概念层级的成员；拿不准时宁可放进「其他重要新闻」也不硬塞。
4. **新增题材需先更新本文件**：在报告中引入新题材标签前，必须在此补充定义，保持唯一依据。
